# Contributing

Thank you for your interest in LitniceLM.

This project does not accept external code contributions. Pull requests
will be closed without review; please do not take this personally.

You are very welcome to:

- report bugs and ask questions through
  [GitHub Issues](https://github.com/leonidpur/litnicelm/issues) or
  [GitHub Discussions](https://github.com/leonidpur/litnicelm/discussions);
- request a commercial license by email to
  [purgalin.dev@gmail.com](mailto:purgalin.dev@gmail.com).
